C. The supplied frontend currently persists tasks locally after a successful AWS request, but events and routines are localStorage-only.
The backend in this ZIP supports /events and /routines, but the frontend still needs GET/POST/PUT/DELETE fetch calls for those resources. It also needs to load AWS records during startup before renderAll().
Do not delete localStorage data until you have successfully migrated it and verified the records in DynamoDB.

D. Reminder records are stored in /reminders only when the frontend calls POST /reminders.
The current syncReminderToAWS() function does this for opted-in task/event reminders, but only after a task/event is saved. This backend does not yet send email. For actual email delivery, configure EventBridge Scheduler + Amazon SES separately.
